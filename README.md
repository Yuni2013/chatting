# Chatting

서버 없이 WebRTC DataChannel로 두 브라우저를 직접 연결하는 간단한 P2P 채팅입니다.

## 실행 방법

1. GitHub Pages를 켜거나 `index.html`을 HTTPS 환경에서 엽니다.
2. 두 사용자가 각자 페이지를 엽니다.
3. 양쪽 모두 닉네임을 입력합니다.
4. 호스트는 채팅방 ID를 정하고 **초대 코드 생성**을 누릅니다.
5. 호스트가 초대 코드를 참가자에게 전달합니다.
6. 참가자는 코드를 붙여넣고 **참가 및 응답 코드 생성**을 누릅니다.
7. 참가자가 만든 응답 코드를 호스트에게 전달합니다.
8. 호스트가 응답 코드를 붙여넣고 **응답 코드 적용**을 누릅니다.
9. 연결되면 채팅을 시작할 수 있습니다.

## 메시지 저장

- 메시지를 보내거나 받으면 해당 브라우저의 `localStorage`에 자동 저장됩니다.
- 같은 브라우저에서 같은 채팅방 ID로 다시 연결하면 이전 기록을 불러옵니다.
- 기록은 각 사용자의 브라우저에 따로 저장됩니다.
- 한쪽에서 기록을 삭제해도 상대방의 기록에는 영향을 주지 않습니다.
- 브라우저 저장 데이터를 지우거나 다른 기기를 사용하면 기록을 불러올 수 없습니다.

## 제한 사항

- 서버가 없으므로 상대방이 오프라인일 때 메시지를 전달하거나 보관할 수 없습니다.
- 브라우저를 닫으면 해당 P2P 연결은 종료됩니다. 다시 대화하려면 새 초대/응답 코드를 교환해야 합니다.
- STUN만 사용하므로 일부 네트워크에서는 연결이 되지 않을 수 있습니다. 그런 환경에는 TURN 서버가 필요하지만, TURN 서버를 사용하면 별도 서버 구성이 필요합니다.
- 이 앱은 현재 1:1 채팅용 기본 버전입니다.
